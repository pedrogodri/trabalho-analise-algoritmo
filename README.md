# mercado de ações

#### Deve possuir varias **empresas**, nas quais possuem seus nomes e valores de ações.
#### As **ações** das empresas podem ser compradas ou vendidas por **investidores**.
#### Os **investidores** registram a compra/venda a um certo valor e quando o valor for igual ao registrado, deve ocorrer a ação e o valor das ações deve alterar.
#### **Investidores** também podem se registrar para receber atualizações em tempo real de mudanças no valor da ação da empresa.

## Estrategia

#### Usar padrão de projeto Observer, no qual vai observar os valores e emitir ações conforme as regras pré estabelecidas.
#### Deve usar os conceitos básicos de clean code, object calisthenics e o padrão de projeto selecionado.
